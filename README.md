# 🏆 Веб-сайт аукциона

Современная веб-платформа для проведения онлайн-аукционов, построенная на Spring Boot с использованием передовых фронтенд-технологий. Проект позволяет пользователям создавать, просматривать и участвовать в онлайн-аукционах с удобным и интуитивным интерфейсом.

## 📋 Описание проекта

**Auction Web Site** — это полнофункциональное приложение, разработанное для проведения онлайн-аукционов. Платформа предоставляет пользователям возможность выставлять лоты на аукцион, делать ставки и управлять своей аукционной деятельностью через удобный веб-интерфейс.

## 🚀 Быстрый старт

### Предварительные требования
- **Java 21** или выше
- **Maven 3.6+**
- **PostgreSQL 12+**
- **Node.js 18+** (для разработки frontend)

### Установка Backend

1. **Клонируем репозиторий**
```bash
git clone https://github.com/LipatovMatvey/AuctionWebSite.git
cd AuctionWebSite
```

2. **Настраиваем PostgreSQL**
```bash
# Создаем базу данных
createdb auctionwebsite

# Обновляем application.properties с учетными данными базы данных
# src/main/resources/application.properties
spring.datasource.url=jdbc:postgresql://localhost:5432/auctionwebsite
spring.datasource.username=ваше_имя_пользователя
spring.datasource.password=ваш_пароль
```

3. **Собираем проект**
```bash
mvn clean install
```

4. **Запускаем приложение**
```bash
mvn spring-boot:run
```

Backend будет доступен по адресу `http://localhost:8080`

### Установка Frontend

1. **Устанавливаем зависимости**
```bash
npm install
```

2. **Запускаем сервер разработки**
```bash
npm run dev
```

## 📦 Основные зависимости

### Backend зависимости
| Зависимость | Назначение |
|-----------|---------|
| spring-boot-starter-web | REST API и поддержка веб |
| spring-boot-starter-data-jpa | ORM для работы с БД |
| postgresql | Драйвер базы данных |
| lombok | Сокращение шаблонного кода |
| spring-boot-starter-validation | Валидация входных данных |

### Frontend зависимости
- Astro — генерация статических сайтов
- MDX — Markdown с компонентами React
- Bootstrap 5.3.8 — компоненты адаптивного интерфейса

## ✨ Функциональность

- 🏷️ **Каталог лотов**: Создание и управление аукционными товарами
- 💰 **Система ставок**: Размещение и управление ставками на товары
- 👤 **Управление пользователями**: Безопасная аутентификация и профили
- 📊 **Управление аукционами**: Просмотр активных, завершенных и архивных аукционов
- 🔍 **Поиск и фильтрация**: Поиск товаров по категориям и критериям
- 📁 **Загрузка файлов**: Поддержка изображений товаров и документации
- 📱 **Адаптивный дизайн**: Работает на мобильных устройствах, планшетах и десктопах
